# A Pen Lovers Paradise — Website redesign concept

A responsive static storefront concept built with HTML, CSS, and vanilla JavaScript. The project includes the provided approved logo and a frontend-only demo cart.


## Publish with GitHub Pages
1. Create a new GitHub repository (or use an existing repository intended for this site).
2. Upload **all contents** of this project folder to the repository's root (ensure `index.html`, `styles.css`, `script.js`, and `assets/` are at the root level, not inside another nested folder).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then Save.
6. Wait for the Pages deployment to finish. The published URL will appear in Settings → Pages.

## Included
- Responsive desktop/tablet/mobile layout and mobile navigation
- Featured product grid based on current product names/prices shown on the existing store homepage
- Category filters and product search
- Product quick-view modal
- Demo shopping bag with add, quantity controls, remove, subtotal, and persistence in local browser storage
- Smooth anchor navigation, reveal animations, and original-store links
- Approved logo image supplied by the client

## Important demo / integration notes
- The shopping bag is frontend-only. It does **not** submit orders, process payments, reserve inventory, or calculate real shipping/taxes.
- Product purchase links currently route to the original store homepage. Individual WooCommerce product links should be added/verified before launch for each product.
- Product cards use decorative CSS/Unicode illustrations rather than copied catalog images. Replace them with licensed/approved product photos for a production storefront.
- The newsletter form is a demonstration only; it is not connected to an email marketing service and does not collect or store submissions.
- Product names and prices were transcribed from the existing store homepage at the time this concept was prepared; confirm pricing, availability, product details, and product-specific URLs before publishing.
- Social profile links were not added because verified social links were not available in the source reviewed.
- Consider connecting the final design to the store's existing WooCommerce/catalog system if live product, stock, checkout, and order management are required.
